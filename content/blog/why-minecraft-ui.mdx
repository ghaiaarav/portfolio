## The idea

When I was thinking about how to make my portfolio memorable, I kept coming back to Minecraft's main menu. It's instantly recognizable, nostalgic, and fun.

Every button maps to a section of my portfolio — projects, experience, skills — but the interface feels like loading into a game.

## The build

Built with Next.js, a rotating CSS cubemap panorama, synthesized click sounds, and a lot of pixel-perfect CSS. The content lives in JSON and MDX files so I can update everything without touching components.
